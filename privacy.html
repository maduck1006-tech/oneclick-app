Privacy Policy

Last updated: November 6, 2026

원클릭 (OneClick) ("the app") is a personal macOS desktop app operated by an individual, 김영진 (contact: maduck1006@gmail.com). It uses YouTube API Services to upload videos to the operator's own YouTube channel.

1. YouTube API Services and Google

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

2. Information the app accesses

  • With your permission through Google OAuth 2.0, the app receives an access token and a refresh token for the scopes youtube.upload and youtube.readonly.
  • It reads the connected channel's ID, title and avatar URL (to show which channel is connected) and the upload/processing status of videos it uploaded.
  • It sends the video file, title, description, tags, category, privacy/schedule settings and thumbnail that you chose to YouTube.

3. How the information is used, stored and shared

  • Information is used only to upload your videos and show upload progress inside the app.
  • The OAuth client file and the refresh token are stored only on your Mac, encrypted with the macOS Keychain (Electron safeStorage). An upload history (video ID, title, time) is stored as a local file in the app's output folder.
  • The app has no server. It does not sell, share or transfer YouTube data or any personal information to third parties, and it does not use cookies, analytics or advertising.

4. Deleting data and revoking access

  • Press "Disconnect" in the app's settings to delete the stored refresh token immediately. Deleting the app's data folder (~/Library/Application Support/원클릭) removes all stored data.
  • You can revoke the app's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • Data obtained through YouTube API Services is not kept longer than needed; channel information is refreshed or deleted within 30 days, and all stored data is deleted when access is revoked.

5. Changes and contact

This policy may be updated; the date above will change. Questions: maduck1006@gmail.com.
