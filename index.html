원클릭 — a personal macOS app for the "AI 수익설계자" YouTube channel

원클릭 (OneClick) is a desktop app for macOS built and used by one individual creator (김영진) to prepare Korean videos for the channel AI 수익설계자 and upload them to that same channel.

How it uses YouTube API Services

  • Signs in with the owner's Google account through Google OAuth 2.0 (desktop loopback flow with PKCE).
  • Scopes: youtube.upload (upload videos, set thumbnails) and youtube.readonly (read the connected channel name and the processing status of uploaded videos).
  • Endpoints: videos.insert (resumable upload), thumbnails.set, videos.list, channels.list.
  • Before each upload the owner reviews the title, description, tags, privacy or schedule time and the altered/synthetic content disclosure.

The app is not sold or distributed, has no other users and has no server. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service.
